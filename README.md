# Stake Challenge Intelligence — version en ligne

Audit indépendant des challenges du forum Stake Community (section *Past Events*), non affilié à Stake.
Copie en lecture seule du dashboard local : mêmes pages et mêmes calculs, exécutés dans le navigateur
à partir de la base `data/audit.sqlite.gz` (SQLite, base du 2026-10-23).

Ce dépôt est généré par `npm run build:site` dans le projet local ; ne pas le modifier à la main.
Publication : GitHub Pages, branche `main`, dossier racine.
